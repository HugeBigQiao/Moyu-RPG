# 开发指南

## 1. 环境

- Python 3.12+（用 uv 管依赖）
- Node 20+（前端构建）
- 数据库不用装：默认 SQLite

```powershell
cd backend;  uv sync
cd ../frontend; npm install
```

## 2. 跑起来

```powershell
# 一键
.\start.bat

# 或分开
cd backend;  uv run python run.py            # 8770
cd frontend; npm run dev                     # 5173，/api 代理到 8770
```

## 3. 测试

```powershell
cd backend
uv run pytest -q                     # 101 个单测
uv run python scripts/api_smoke.py   # 24 项接口冒烟（要先起服务）
uv run python scripts/smoke.py mirror # 不开服务，直接跑一局引擎

cd ../frontend
node scripts/ui_smoke.mjs            # 23 项无头浏览器检查
```

## 4. 改设定（最常见的事）

设定全在 `backend/content/*.json`。改完不用重启：

```powershell
curl -X POST http://127.0.0.1:8770/api/admin/reload
# 或者浏览器控制台：fetch('/api/admin/reload',{method:'POST'}).then(r=>r.json()).then(console.log)
```

### 加一个事件

编辑 `content/events.json` 的 `events` 数组：

```json
{
  "id": "ev_new_thing",
  "name": "事件名",
  "grade": 3,
  "scope": "general",
  "industries": ["medical"],
  "text": "一句话背景。",
  "hook": "这个人为什么牵涉进来。",
  "traits": ["胆大"],
  "weight": 15
}
```

规则：`grade` 1–4（甲→丁）；`grade ≤ 2` 必须是 `scope: "mission"` 并写 `missions`；
`traits` 里的名字必须在 `traits.json` 里存在。

### 加一座城市

`content/world.json`：

- `cities` 里加条目（`tier` 必须存在于 `tiers`，`industries` 必须是已知行业 id）
- `city_geo` 里加经纬度 `"城市id": [纬度, 经度]`
- `city_factions` 里加当地势力

### 加一个固定剧本

1. `content/scenarios.json` 里加场景流（`investigate` / `combat` / `choice` / `ending`）
2. `content/missions.json` 里加任务条目，`scenario_id` 指向它，`cities` 指定可发案城市

### 加一件装备 / 一条特性

- 装备：`content/equipment.json`
- 特性：`content/traits.json`（`effect` 的键要和 `engine/sheet.py` 的算法对上）

## 5. 加一个接口

1. `app/api/schemas.py` 加请求体（如果需要）
2. 在对应模块（`archive.py` / `game.py` / `characters.py` / `sessions.py`）加路由：

```python
@router.get("/something/{id}")
async def api_something(id: str, db: AsyncSession = Depends(get_db)):
    ...
```

3. 前端 `src/api.js` 里加一行封装
4. `python scripts/api_smoke.py` 补一条断言

## 6. 改数据库结构

```powershell
cd backend
# 1. 改 app/models.py
# 2. 生成迁移
uv run alembic revision --autogenerate -m "说明"
# 3. 检查生成的脚本，非空列必须带 server_default
# 4. 应用
uv run alembic upgrade head
```

**踩过的坑**：`--autogenerate` 给已有表加非空列时不写默认值，
生产数据上会直接 `NotNullViolation`。正确写法是

```python
op.add_column("t", sa.Column("x", sa.Integer(), nullable=False, server_default="0"))
op.alter_column("t", "x", server_default=None)
```

## 7. 前端

- 新页面：`src/views/Xxx.vue` + `src/router.js` 加一条路由（`meta.title` 会显示在顶栏）
- 新接口：`src/api.js` 加方法
- 设置项：`src/settings.js` 加字段，`SettingsPanel.vue` 加控件，CSS 里用 `data-theme` / `var(--base-size)`
- 主题：`src/style.css` 里 `:root[data-theme='xxx']` 覆盖变量即可

## 8. 提交前检查

```powershell
cd backend;  uv run pytest -q
cd ../frontend; npm run build
```

- 新内容要能通过 `uv run python -c "from app.content._store import reload_all; print(reload_all())"`
- 不提交 `backend/.env`、`backend/data/*.db`、`frontend/dist/`
- 提交信息用「动词: 说明」的格式
