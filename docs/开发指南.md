# 开发指南

> 2026-11-17 起后端是 Node/TypeScript + cordis；旧 Python/FastAPI 实现已删除。
> 架构见 [架构.md](架构.md)，迁移过程见 [cordis迁移.md](cordis迁移.md)。

## 1. 环境

- **Node 24+**（原生 TS 执行与 `node:sqlite` 都要求；本机 26.8.1 验证）
- 前端构建用同一套 Node；不需要 Python
- 数据库不用装：默认 SQLite；要 PG/MySQL 时自己起服务并改 `MOYU_DATABASE_URL`

```bash
cd server && npm install
cd ../frontend && npm install
```

## 2. 跑起来

```bash
# Windows 一键
.\start.bat

# Linux / macOS 一键（首次先 chmod +x start.sh）
./start.sh            # 支持 --port 9000 / --no-open / --rebuild

# 或手动
cd server && npm start          # 8888
cd frontend && npm run dev      # 5173，/api 代理到 8888
```

后端开发模式：`cd server && npm run dev`（`node --watch`，改 TS 自动重启）。
启动时会自动建表/补列，不需要单独的迁移命令。

环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `MOYU_HOST` | `127.0.0.1` | 监听地址 |
| `MOYU_PORT` | `8888` | 端口 |
| `MOYU_DATABASE_URL` | `sqlite://<repo>/server/data/moyu.db` | `sqlite://`、`postgresql://`、`mysql://` |
| `MOYU_CONTENT_DIR` | `server/data/content` | 内容 JSON |
| `MOYU_FRONTEND_DIST` | `frontend/dist` | 前端产物 |

## 3. 测试

```bash
cd server
npm test                              # 268 个 vitest
npm run typecheck                     # tsc --noEmit
npm run smoke -- http://127.0.0.1:8888  # 28 项接口冒烟（需先起服务）

cd ../frontend
npm run typecheck                     # vue-tsc --noEmit
node scripts/ui_smoke.mjs             # 52 项无头浏览器检查
```

`server/test/fixtures/*.json` 是从迁移前的 Python 引擎导出的「标准答案」：
PRNG、检定、五行、角色卡、35 局回放、抽卡、NPC、随机任务、成长线、KP、档案编辑。
`test/parity/` 逐字段比对，任何一处漂移都会失败。fixtures 已冻结；
如果确实要改行为，先明确改哪几条断言，再改 fixtures 与 TS，别让「顺手重构」悄悄改了规则。

## 4. 改设定（最常见的事）

设定全在 `server/data/content/*.json`。改完不用重启：

```bash
curl -X POST http://127.0.0.1:8888/api/admin/reload
```

### 在界面里改

档案页每一类右上角都有「＋ 新增 / 编辑 / 删除」：填表保存，直接写回 JSON，
写完自动重载。复杂结构（比如剧本的 `scenes`）仍然建议直接改 JSON。

删除会被引用拦住：比如删一座还有任务发案、还有人物登记的城市，会直接告诉你谁在用。

### 加一个事件

编辑 `content/events.json` 的 `events` 数组：

```json
{
  "id": "ev_new_thing",
  "name": "事件名",
  "grade": 3,
  "scope": "general",
  "industries": ["medical"],
  "text": "一句话背景。",
  "hook": "这个人为什么牵涉进来。",
  "traits": ["胆大"],
  "weight": 15
}
```

规则：`grade` 1–4（甲→丁）；`grade ≤ 2` 必须是 `scope: "mission"` 并写 `missions`；
`traits` 里的名字必须在 `traits.json` 里存在。

### 加一座城市

`content/world.json`：

- `cities` 里加条目（`tier` 必须存在于 `tiers`，`industries` 必须是已知行业 id）
- `city_geo` 里加经纬度 `"城市id": [纬度, 经度]`
- `city_factions` 里加当地势力

### 加一个固定剧本

1. `content/scenarios.json` 里加场景流（`investigate` / `combat` / `choice` / `ending`）
2. `content/missions.json` 里加任务条目，`scenario_id` 指向它，`cities` 指定可发案城市

### 加一件装备 / 一条特性

- 装备：`content/equipment.json`
- 特性：`content/traits.json`（`effect` 的键要和 `core/sheet.ts` 的算法对上）

## 5. 加一个接口

1. `server/src/api/schemas.ts` 加请求体（如果需要）
2. 在对应模块（`archive.ts` / `characters.ts` / `game.ts` / `sessions.ts`）里注册：

```ts
server.get('/api/something/:id', async (req, res) => {
  const row = await db.get('SELECT * FROM characters WHERE id = ?', [Number(req.params.id)])
  if (!row) throw new HttpError(404, '没有这个节点')
  sendJson(res, 200, { ... })
})
```

3. 前端 `src/shared/api.ts` 加一行封装
4. `server/scripts/api-smoke.ts` 补一条断言（它打的是同一套 HTTP 接口）

依赖服务用 `ctx.content` / `ctx.db` / `ctx.rules`，不要直接 import 别的插件。
业务错误抛 `HttpError(status, "中文原因")`，HTTP 层会回 `{detail}`。

## 6. 改数据库结构

1. 改 `server/src/db/schema.sql`（SQLite）、`schema.postgres.sql`、`schema.mysql.sql`
2. 改 `server/src/db/repo.ts` 的行映射与 `insertCharacter` 的字段
3. 老库补列：在 `Db.ensureRulesVersion` 旁边加一个 `ensureXxx`，用信息模式判断列是否存在，
   不要无脑 `ALTER TABLE`（重复执行会报错）
4. 三套 schema 同步改，否则 PG/MySQL 会在启动时缺列

当前只支持「基线建表 + 补列」；需要复杂迁移时再引入顺序 SQL 文件与版本号。

## 7. 前端

TypeScript + Vue 3。前端按功能分区，不再分 views / components：

```
src/app/       壳（App.vue、router.ts、顶栏·设置·遮掩）
src/areas/     一个目录一个功能：HomeView · archive/ · play/
src/shared/    跨区域复用：api.ts · types.ts · settings.ts · stealth.ts · flash.ts
```

- **类型**：接口响应结构写在 `src/shared/types.ts`，`api.ts` 的方法都带返回类型；
  组件用 `defineProps<{...}>()` / `defineEmits<{...}>()`，不写运行时 props 对象。
- **改接口时**：先改 `shared/types.ts`，再跑 `npm run typecheck`，最后 `npm run build`。
- `assets/china.ts` 是已生成的地图轮廓，别手改。
- **放哪里**：新增或修改一个功能，先找 `src/areas/<区域>/`；页面、页内组件、字段规格都放一起。
  只有被第二个区域用到的东西才提到 `src/shared/`；顶栏/设置这类全站壳放 `src/app/`。
- 主题：`src/style.css` 里 `:root[data-theme='xxx']` 覆盖变量即可。
- 配色：组件里**不要写死 hex**。新颜色先加语义变量（`--surface-btn` / `--heading` / `--text-body` 这类），
  再在 `:root`、`[data-theme='light']`、`[data-theme='ink']` 各赋一次；写死深色会让浅色主题出现黑块（踩过）。

## 8. 提交前检查

```bash
cd server;  npm test; npm run typecheck
cd ../frontend; npm run typecheck; npm run build
```

- 新内容要能通过 `POST /api/admin/reload`，且 `/api/admin/content` 的 `errors` 为空
- 不提交 `server/data/*.db`、`frontend/dist/`、`server/node_modules/`
- 提交信息用「动词: 说明」的格式

## 9. 注释规范

每个 TS 模块开头固定三段：

```ts
/**
 * 一句话说这个文件是什么。
 *
 * 职责：
 *     这个文件负责什么（一句话，具体）。
 * 为什么需要：
 *     不写它会怎样（说清动机，不写「为了规范」）。
 * 上下游：
 *     上游：谁给它数据；下游：它把数据交给谁。
 */
```

函数 docstring 写参数、为什么需要、输出；块级注释只写「这段在处理什么」，不复述代码。
`core/*` 是纯函数，改动必须同时对拍；`api/*` 只做组装，不写规则。

## 10. 遮掩模式怎么扩展

遮挡层在 `frontend/src/app/StealthOverlay.vue`，状态与快捷键在
`frontend/src/shared/stealth.ts`，持久化在 `settings.ts`。加一种模式：

1. `settings.ts` 的 `stealthMode` 增加枚举；
2. `SettingsPanel.vue` 增加一张卡；
3. `StealthOverlay.vue` 加一个分支；
4. `ui_smoke.mjs` 的「三套主题 + 三种遮掩」计数改成四。
