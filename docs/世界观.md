# 《玄门诡事录》设定档 v1.1

> 这份文档和 `backend/data/content/*.json` 是同一套东西：
> `world.json`（国家/教派/机构/人物/行业/城市）、`events.json`（事件）、
> `traits.json`（特性）、`missions.json`（任务）、`equipment.json`（装备）。
> 文档负责讲「为什么这样」，JSON 负责讲「具体是什么」。
> 改设定请改 JSON，然后 `POST /api/admin/reload`，不用改代码。

## 一、基础背景设定

**时代**：当代。有手机、监控、网约车、短视频，也有箓职、香火、阴兵。

**世界怎么运转**：人心里的郁结会淤积成「阴浊」，超过阈值就具象化成**祟物**。
祟物不是外来的怪物，是没被处理掉的东西长出来的。所以处置祟物的核心不是「打赢」，
是**了结**——把一桩因果处理干净。

**三个基本事实**（全部已实现）：

1. **祟物有三态**：灵体（只有法术/符箓能碰）→ 附身（伤宿主即伤它，物也能伤）
   → 实体（物理有效，五行伤害 ×1.5）。所以普通人不是没用的，关键是把祟物逼到能碰的状态。
2. **五行决定伤害**：克 ×1.5、被克 ×0.5、煞 ×1.25。
3. **一切都有代价**：超度记功德，剿灭积阴债，用阴器背业障。

**社会的态度**：官方承认、民间半信半疑、媒体不敢写。祟物不上新闻，只上档案。

## 二、国家

| 国家 | 体制 | 对祟物的态度 |
| --- | --- | --- |
| **夏** | 中央集权的现代国家，地方道门与官府共治，「外儒内道」 | 克制务实：要处置，但不能惊动民生 |
| **北岭** | 军人执政的联邦，崇拜体修与兵家 | 只剿灭不超度，越剿越多，边防线越修越长 |
| **东海** | 群岛商业联邦（城邦联盟） | 只认买卖：禁符、阴器、野神名录都从这里过一手 |

夏是主舞台：明面上是部委、法院、公安，暗线是授箓、备案、评级。
修行者在法律上是公民，在册籍上是资源。

## 八、事件库

**一个人物的来路，本质上是一串事件。**

事件分四级：甲 > 乙 > 丙 > 丁。等级越高：

- **越稀罕**（权重低）
- **越少被通用**——甲级事件只挂在某几个特定任务上，丁级事件哪里都能长

| 等级 | 适用范围 | 数量 | 典型 |
| --- | --- | --- | --- |
| 甲 | 限定任务（1–2 个） | 5 条 | 镜前自尽、水下活下来的人、被抬起来的神、第七天还在工位、最后一单没跑完 |
| 乙 | 限定任务（2–3 个） | 4 条 | 矿难埋了三天、庙里长大的孩子、在精神科住过一年、旧案卷宗里的一页 |
| 丙 | 通用 | 8 条 | 倒了十年夜班、孩子走丢过四小时、替人收过债、太平间守过夜… |
| 丁 | 通用 | 7 条 | 半夜三点十七分醒、养了十二年的狗死了、失眠七年、有收藏癖… |

每条事件带 1–2 个**特性**（见 `traits.py`，同样分甲乙丙丁），也带一个**钩子**
（这个人为什么牵涉进来）。

**兼容规则**（已实现为 `events.compatible`）：
通用事件看城市行业与城市限定；限定任务的事件必须和该任务匹配。

## 九、任务

两种任务：

- **固定任务**：写在剧本库里的案子，绑定城市。现在五个：镜中鬼、写字楼血案、送纸、夜航、旱骨（都在南屿及附近）。
- **随机任务**：由「城市 + 事件」现场拼出来，同一座城市能反复出不同的案子。

**难度与报酬都从事件推**：

```
难度 = Σ(5 − 事件等级) × 2 + 祟物体量/10 + 城市等级修正
报酬 = 难度 × 3（功德）
```

所以「甲级事件带出来的人」= 难案 = 高报酬。难度对应等级：丁 ≤ 8、丙 9–15、乙 16–23、甲 ≥ 24。

## 十、人物生成

### 玩家自建（单人模式下的唯一主角）
- 六维**点数分配**：总分 72，单项 6–18
- 选流派、本命五行、出身城市
- 选最多 3 条**通用事件**（受城市行业限制）→ 决定初始特性
- 初始箓职初真，功德 20

### 系统随机（其余所有人物）
- **随机城市**（按人口加权，大城市更容易出人）
- **随机事件串**：数量在 1 ~ 该城市事件上限之间随机
- 特性由事件带出（最多 4 条）
- 稀有度由出身事件决定：甲级 → 天品，乙 → 玄品，丙（≥3 条）→ 灵品，其余凡品
- 属性骰池受城市等级加成（特级 +3 / 四级 −1）
- 自动算出**难案倾向**与**报酬基准**，写进档案

> 这条的意思是：**你不是在抽卡，你是在给这个世界补人**。
> 大城市里随便遇到一个人，可能背着十条事件；小镇上的人，两条就到头了。

## 十一、数值规则（简述）

| 项 | 规则 |
| --- | --- |
| 属性 | 力/敏/体/智/意/感，3–20 |
| 气血 | 体 × 5 |
| 灵力 | 流派主属性 × 2（符箓=智、内丹/剑修=意、体修=体、暗器=敏） |
| 理智 | 意 × 5 |
| 剑意 / 杀气 | 意 × 2 / 敏 × 2 |
| 每日符力 | 智 × 2（画符预算，与战斗灵力分开） |
| 检定 | d100，目标 = 技能值 + 五行修正；≤1/5 大成功，≤1/2 极难 |
| 授箓 | 初真 → 盟威（3 案）→ 五雷（功德 50 + 心魔试炼）→ 天师（功德 80 + 3 善果 + 8 案） |
