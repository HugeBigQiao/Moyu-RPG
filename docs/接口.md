# 接口

所有接口都在 `/api` 下，返回 JSON。文档页：`http://127.0.0.1:8770/api/docs`。

## 档案（只读内容）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/world` | 国家、教派、机构、人物、行业、世界背景、城市分级、城市（含经纬度与势力） |
| GET | `/api/events` | 事件库（含等级、适用范围、赋予特性） |
| GET | `/api/missions` | 固定任务 + 各城可发的任务类型 |
| GET | `/api/missions/random?city=&count=` | 随机任务样例（不落库） |
| GET | `/api/equipment` | 装备库 |
| GET | `/api/traits` | 人物特性库 |
| GET | `/api/scenarios` | 剧本、祟物、符箓、英灵、商店（打包） |

## 内容管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/content` | 内容目录、文件清单、加载错误 |
| POST | `/api/admin/reload` | 强制重读 `data/content/*.json`，返回每个模块状态 |

## 人物

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/roster` | 在册人物列表 + 抽卡概率表 |
| POST | `/api/npcs` | 随机生成人物 `{count, city?, mission?}` |
| POST | `/api/characters/roll` | 掷一套玩家属性（总值恒 72） |
| POST | `/api/characters` | 玩家自建 `{name, school, element, city, attrs?, events?}` |
| POST | `/api/gacha` | 旧版抽卡（保留兼容） |
| GET | `/api/characters/{id}` | 角色卡全量：属性、技能、特性、出身事件、英灵、商店货架、晋升要求 |
| POST | `/api/characters/{id}/promote` | 授箓晋升 |
| POST | `/api/characters/{id}/trial` | 心魔试炼 |
| POST | `/api/characters/{id}/buy` | 功德兑换 `{item_id}` |
| DELETE | `/api/characters/{id}` | 注销人物 |

## 游戏

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/dashboard` | 总览：人数、会话数、稀有度分布、最近事件 |
| GET | `/api/game/map` | 地图数据：城市、坐标、人数、任务数、势力数 |
| GET | `/api/game/city/{id}` | 城市面板：信息、任务、随机任务样例、在册人物、势力 |

## 会话

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 开固定任务 `{character_id, scenario_id}` |
| POST | `/api/sessions/random` | 开随机任务 `{character_id, city?}` |
| GET | `/api/sessions/{id}` | 当前场景、指标、可用操作、事件流 |
| POST | `/api/sessions/{id}/act` | 执行操作 `{action}`，返回新状态与本次事件 |

### 操作 id 的格式

| 前缀 | 例子 | 含义 |
| --- | --- | --- |
| `opt:` | `opt:tape` | 勘查场景里的某个选项 |
| `draw:` | `draw:binghuo` | 画一张符 |
| `attack:` | `attack:melee` | 战斗招式（melee/spell/blade/hidden） |
| `talisman:` | `talisman:gengjin` | 引动已画的符 |
| `summon:` | `summon:guanyu` | 请神 |
| `ward` / `env` / `flee` | — | 结界 / 借环境 / 撤离 |
| `choice:` | `choice:purify` | 抉择 |
